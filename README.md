# Lemon Academia - Angular Web Application

A modern e-learning and handcrafted art creation platform built with Angular 21, Tailwind CSS v4, and TypeScript.

## Features
- **44 Routes Parity**: Comprehensive coverage across Public pages, Student portal, Admin Management portal, and Trainer studio.
- **Role-Based Authentication**: Supports Student, Trainer, and Admin roles with guards, cookies/localStorage synchronization, and dev proxy integration.
- **Artisan Course Catalog & Lippan Studio**: Full course listing, interactive learning modules, progress tracking, and student gallery.
- **Session Scheduling**: Live Zoom workshop date calculations with automatic status badges (`LIVE`, `UPCOMING`, `COMPLETED`).
- **Admin & Trainer Portals**: Course CRUD, application reviews, coupon creation, blog CMS, and student management.

## Getting Started

### Development Server
```bash
npm start
```
Navigate to `http://localhost:4200/`. The app will automatically reload if you change any source files.

### Build
```bash
npm run build
```
Build artifacts are stored in the `dist/` directory.
